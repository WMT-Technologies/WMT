# WMT Backend Integration Guide\n\nThis document describes how the AI File & Image Analysis module integrates with the WMT platform.\n\n## Architecture\n\n```\nUser Upload\n    ↓\nSupabase Storage\n    ↓\nOpenAI Vision API / Google Document AI\n    ↓\nStructured Data Extraction\n    ↓\nPermission Validation (WMT Role Check)\n    ↓\nUser Approval\n    ↓\nWMT API Integration\n    ↓\nData Saved in WMT Modules\n```\n\n## Supported WMT Modules\n\n### HR Module\n\n**Endpoint:** `/api/v1/hr/employees`\n\n**Document Type:** `employee_document`\n\n**Extracted Fields:**\n```json\n{\n  \"firstName\": \"John\",\n  \"lastName\": \"Doe\",\n  \"employeeId\": \"1234567890\",\n  \"nationality\": \"USA\",\n  \"department\": \"Engineering\",\n  \"position\": \"Senior Engineer\",\n  \"dateOfBirth\": \"1990-01-15\",\n  \"documentExpiry\": \"2025-12-31\"\n}\n```\n\n**Required Permissions:** `HR_ADMIN` or `EMPLOYEE_MANAGER`\n\n### Finance Module\n\n#### Expenses\n\n**Endpoint:** `/api/v1/finance/expenses`\n\n**Document Types:** `receipt`, `expense_report`\n\n**Extracted Fields:**\n```json\n{\n  \"vendor\": \"Office Supplies Co\",\n  \"amount\": 250.50,\n  \"date\": \"2024-01-15\",\n  \"category\": \"Office Supplies\",\n  \"items\": [{\"name\": \"Pen Set\", \"qty\": 5, \"price\": 50.10}],\n  \"taxAmount\": 0.00,\n  \"paymentMethod\": \"credit_card\",\n  \"receiptNumber\": \"RCP-2024-001\"\n}\n```\n\n**Required Permissions:** `FINANCE_ADMIN` or `EXPENSE_MANAGER`\n\n#### Transactions\n\n**Endpoint:** `/api/v1/finance/transactions`\n\n**Document Type:** `transaction_screenshot`\n\n**Extracted Fields:**\n```json\n{\n  \"amount\": 1000.00,\n  \"date\": \"2024-01-15\",\n  \"account\": \"Checking-1234\",\n  \"type\": \"transfer\",\n  \"description\": \"Payment to Vendor XYZ\",\n  \"referenceNumber\": \"TRX-2024-001\",\n  \"status\": \"completed\"\n}\n```\n\n**Required Permissions:** `FINANCE_ADMIN` or `TRANSACTION_MANAGER`\n\n#### Invoices\n\n**Endpoint:** `/api/v1/finance/invoices`\n\n**Document Type:** `invoice`\n\n**Extracted Fields:**\n```json\n{\n  \"vendor\": \"Tech Solutions Inc\",\n  \"invoiceNumber\": \"INV-2024-001\",\n  \"date\": \"2024-01-15\",\n  \"dueDate\": \"2024-02-15\",\n  \"amount\": 5000.00,\n  \"items\": [{\"description\": \"Consulting Services\", \"qty\": 1, \"price\": 5000}],\n  \"taxAmount\": 0.00,\n  \"purchaseOrder\": \"PO-2024-001\"\n}\n```\n\n**Required Permissions:** `FINANCE_ADMIN` or `INVOICE_MANAGER`\n\n### Sales Module\n\n#### Inquiries\n\n**Endpoint:** `/api/v1/sales/inquiries`\n\n**Document Type:** `customer_inquiry`\n\n**Extracted Fields:**\n```json\n{\n  \"contactName\": \"Jane Smith\",\n  \"email\": \"jane@example.com\",\n  \"phone\": \"+1-555-0123\",\n  \"product\": \"Construction Software\",\n  \"issue\": \"Need project management features\",\n  \"description\": \"Customer is looking for integrated PM tools\",\n  \"priority\": \"medium\",\n  \"status\": \"new\"\n}\n```\n\n**Required Permissions:** `SALES_ADMIN` or `INQUIRY_MANAGER`\n\n#### Quotations\n\n**Endpoint:** `/api/v1/sales/quotations`\n\n**Document Type:** `customer_inquiry`\n\n**Extracted Fields:**\n```json\n{\n  \"contactName\": \"Jane Smith\",\n  \"email\": \"jane@example.com\",\n  \"phone\": \"+1-555-0123\",\n  \"product\": \"Construction Software\",\n  \"estimatedAmount\": 10000.00,\n  \"validUntil\": \"2024-03-15\"\n}\n```\n\n**Required Permissions:** `SALES_ADMIN` or `QUOTATION_MANAGER`\n\n### Project Module\n\n**Endpoint:** `/api/v1/projects/documents`\n\n**Document Type:** `site_photo`\n\n**Extracted Fields:**\n```json\n{\n  \"title\": \"Site Photo - Foundation Excavation\",\n  \"location\": \"Building A, Floor 1\",\n  \"documentDate\": \"2024-01-15\",\n  \"documentType\": \"site_photo\",\n  \"description\": \"Excavation work in progress\",\n  \"tags\": [\"work_in_progress\", \"excavation\"],\n  \"metadata\": {\n    \"weather\": \"clear\",\n    \"equipmentPresent\": \"excavator, dump truck\"\n  }\n}\n```\n\n**Required Permissions:** `PROJECT_ADMIN` or `DOCUMENT_MANAGER`\n\n## Permission Validation Flow\n\n1. **User uploads file** → Backend gets user ID from header\n2. **Backend queries WMT API** → Fetches user role and permissions\n3. **AI Analysis** → Detects document type and extracts data\n4. **Permission Check** → Validates user has permission for suggested action\n5. **User Review** → Shows extracted data for approval\n6. **Save Decision** → If approved, saves to WMT via appropriate endpoint\n7. **Audit Log** → Records all actions for compliance\n\n## Configuration\n\n### Environment Variables\n\n```bash\n# WMT API\nNEXT_PUBLIC_WMT_API_URL=https://api.wmt.com\nWMT_API_KEY=your-api-key-here\n\n# WMT Permissions (cached)\nWMT_PERMISSION_CACHE_TTL=3600  # 1 hour\nWMT_PERMISSION_CACHE_ENABLED=true\n```\n\n### User Roles\n\n- `ADMIN` - Full access to all document types\n- `SALES` - Customer inquiries, quotations\n- `HR` - Employee documents\n- `FINANCE` - Receipts, invoices, transactions\n- `PROJECT` - Site photos, project documents\n- `USER` - Basic access only\n\n## Error Handling\n\nThe system handles various error scenarios:\n\n### 1. Permission Denied\n```json\n{\n  \"error\": \"Insufficient permissions\",\n  \"code\": \"INSUFFICIENT_PERMISSIONS\",\n  \"details\": \"User role 'SALES' does not have permission for action 'create_employee_profile'\"\n}\n```\n\n### 2. Invalid Document Type\n```json\n{\n  \"error\": \"Cannot handle document type\",\n  \"code\": \"CANNOT_HANDLE_DOCUMENT_TYPE\",\n  \"details\": \"User role 'FINANCE' cannot handle 'employee_document' documents\"\n}\n```\n\n### 3. WMT API Error\n```json\n{\n  \"error\": \"Failed to save to WMT\",\n  \"code\": \"WMT_API_ERROR\",\n  \"details\": \"WMT API error: 400 Bad Request\"\n}\n```\n\n### 4. Data Validation Error\n```json\n{\n  \"error\": \"Validation failed\",\n  \"code\": \"VALIDATION_ERROR\",\n  \"details\": [\n    \"name is required\",\n    \"amount must be a number\"\n  ]\n}\n```\n\n## Testing\n\n### Test Credentials\n\n```bash\n# Get test API key from WMT admin panel\nWMT_API_KEY=sk_test_1234567890abcdef\n```\n\n### Test Scenarios\n\n1. **Employee Document Upload**\n   - Upload employee ID photo\n   - Review extracted data\n   - Approve and save to HR module\n\n2. **Receipt Upload**\n   - Upload receipt image\n   - Verify amount and vendor extraction\n   - Save to Finance module\n\n3. **Permission Denial**\n   - Login as SALES user\n   - Try to upload employee document\n   - Should show permission error\n\n## Troubleshooting\n\n### User Role Not Found\n\n**Solution:** Ensure user exists in WMT database and has assigned role.\n\n### Permission Cache Stale\n\n**Solution:** Clear cache or reduce `WMT_PERMISSION_CACHE_TTL`\n\n### WMT API Timeout\n\n**Solution:** Check network connectivity, increase `timeout` in config\n\n## Future Enhancements\n\n- [ ] Batch document processing\n- [ ] Custom extraction templates\n- [ ] Workflow automation\n- [ ] Document tagging and categorization\n- [ ] Integration with WMT reporting\n"
